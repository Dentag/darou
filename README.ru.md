# Darou

[English](README.md) | [Русский](README.ru.md)

Darou — пет-проект для личных видеозвонков на Kotlin и WebRTC. Всё началось с простой цели: соединить два телефона видеозвонком, а затем постепенно прийти к приложению для Android и iOS для небольшого круга людей.

Сейчас это рабочий браузерный прототип с бэкендом на Kotlin. На нём можно изучать установление звонка, обрывы соединения и качество связи перед переходом к нативным мобильным клиентам.

Мобильный каркас использует Kotlin Multiplatform и Compose Multiplatform, русский/английский текст и светлую/тёмную темы. В Android и iOS общий экран входа подключён к авторизации; после успешного ответа показывается приветственный экран. Этот мобильный сценарий ещё не собирался и не тестировался, а звонки не реализованы. Добавлен проект Xcode для iPhone и симуляторов на Apple Silicon; его сборка и поведение на устройствах пока не проверены.

## Что уже работает

- Видео- и аудиозвонки между двумя заранее заданными участниками.
- Приглашение в звонок, принятие, отклонение и завершение.
- Управление камерой и микрофоном во время разговора.
- Прямая передача медиа или ретрансляция через TURN, включая режим «Только TURN».
- Переподключение к сигнальному серверу с минутным окном восстановления и повторным согласованием ICE.
- Показатели качества соединения и скачивание клиентской диагностики.

## Как устроены звонки

Сервер на Kotlin/Ktor отвечает за вход, доступность участников и обмен сообщениями для установления звонка. Клиенты передают эти сообщения через WebSocket, а WebRTC доставляет звук и видео напрямую между ними или через ретранслятор TURN.

Сигнальный сервер не обрабатывает и не записывает медиа. TURN пересылает зашифрованный трафик WebRTC; временные учётные данные для доступа к нему выдаёт бэкенд.

## Технологии

| Часть | Технологии |
| --- | --- |
| Бэкенд | Kotlin, Ktor, Netty, корутины |
| Браузерный клиент | ES-модули JavaScript, HTML, CSS |
| Мобильный каркас | Kotlin Multiplatform, Compose Multiplatform, Android 10+, целевая поддержка iOS 16+ |
| Звонки | WebRTC, сигналинг через WebSocket, STUN/TURN |
| Тестирование | Модульные тесты Kotlin и браузерные сценарии Playwright |
| Сборка и проверки | Gradle, GitHub Actions, проверка репозитория на секреты |

В бэкенде разделены авторизация, управление звонками, сигнальный протокол и транспорт. В браузерном клиенте отдельно устроены интерфейс, доступ к камере и микрофону, WebRTC, сигналинг и диагностика.

Мобильный код разделён на `shared` для клиентской логики, `shared-ui` для общего presentation, а также `androidApp` и `iosApp` для платформенных точек входа. Общий модуль содержит публичные модели авторизации и интерфейсы юзкейсов, а также внутренние реализации с HTTP-репозиторием на Ktor и хранением cookie в памяти. Для сети используются OkHttp на Android и Darwin на iOS; Koin связывает HTTP-клиент, репозиторий, юзкейсы и ViewModel входа. Оба приложения инициализируют Koin при запуске с адресом сервера из локальной конфигурации. iOS-приложение использует SwiftUI для отображения общего Compose-контроллера; Xcode собирает Kotlin-фреймворк через Gradle. Общий экран входа наблюдает состояние ViewModel и отображает загрузку и ошибки запросов. Восстановление сессии и интерфейс выхода ещё не реализованы. Этот клиентский код пока не проверен. Логика звонков ещё не реализована.

Автоматические проверки охватывают переходы состояния звонка, контроль доступа, таймауты, передачу медиа, управление микрофоном и восстановление связи у обоих участников. Браузерные сценарии используют искусственные источники звука и видео и дополняют проверки на физических устройствах.

## Текущий этап и планы

Darou находится на стадии раннего прототипа. Аккаунты и сессии хранятся в памяти, вход работает по демонстрационным кодам, одновременно поддерживается один звонок. Медиа защищены шифрованием WebRTC; независимая проверка ключей собеседника пока не реализована.

Следующие этапы — проверка общих экранов и входа на Android и iOS, затем общий сигналинг и WebRTC на обеих платформах для звонка между телефонами. После этого запланирован переход к полноценному визуальному дизайну. Фоновые входящие звонки и интеграция с системными звонками идут позже. Текстовая переписка и групповые звонки пока не реализованы.
